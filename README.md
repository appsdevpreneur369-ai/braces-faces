# braces-faces

Public website for **Braces & Faces Dental Clinic — Maxillofacial and Orthodontic Centre**, Tadepalli, Vijayawada.
Next.js 14 (App Router, static), Tailwind. Appointment requests go out as a pre-filled WhatsApp message; no backend.

```bash
npm install
npm run dev      # http://localhost:3000
npm run check    # lint + typecheck + tests + build
```

See `CLAUDE.md` for content sources, design rules and deployment.
